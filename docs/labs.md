This is a collection of experiments, side projects, and playgrounds where I explore new technologies, low-level programming, and performance-driven tools.

## 🛠️ Featured Experiments

### Pomonote

**A TUI (Terminal User Interface) for managing tasks.**
Built to explore terminal-based productivity and efficient workflow management.

- **Stack:** Rust / Ratatui
- **Focus:** CLI UX, state management, and terminal rendering.
- [View on GitHub](https://github.com/willnjl/pomonote)

### Rust + WASM Snake

**A classic game engine implementation in the browser.**
An experiment in compiling low-level code to the web to achieve high-performance rendering and memory safety.

- **Stack:** Rust, WebAssembly (WASM), JavaScript
- **Focus:** Memory management, WASM-JS interop, and game logic.
- [View on GitHub](https://github.com/willnjl/Snake-Game-Rust-Wasm)
- [Try it out](https://willnjl.github.io/Snake-Game-Rust-Wasm/)

- **Focus:** Developer experience (DX) and automation.
